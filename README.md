# 💛 Flores Amarillas para Mimi 🐰✨

Un detalle romántico interactivo preparado especialmente para el **21 de Septiembre**, con animación de un ramo de flores amarillas floreciendo de inicio a fin, botón rojo pulsante, una tierna conejita y el mensaje especial en rosa pastel:

> *"Feliz 21 de Septiembre, mi bella conejita mimi, te amo"*

---

## 🚀 ¿Cómo Ejecutarlo?

Tienes **2 opciones increíbles** para mostrárselo a tu novia:

### Opción 1: Aplicación Nativa en Python (Tkinter)
No requiere instalar nada externo, funciona directamente con Python puro:
```bash
python flores_amarillas.py
```
- 🔴 **Botón rojo animado** que palpita en el centro.
- 💥 Al hacer clic, explota en corazones y comienza a dibujarse el ramo de girasoles paso a paso (tallos, hojas, envoltura, pétalos y semillas).
- 🐰 Aparece la conejita Mimi sosteniendo su flor.
- 💖 Texto en **Rosa Pastel** y destellos dorados.
- ✨ Puedes hacer clic en cualquier parte para lanzar fuegos artificiales de corazones.

---

### Opción 2: Experiencia Web Interactiva (Con Música Romántica y Carta Secreta)
Puedes abrir el archivo `index.html` en cualquier navegador (Chrome, Edge, etc.) o ejecutar:
```bash
python lanzador.py web
```
- 🎵 **Música romántica ambiental** generada en tiempo real.
- 💌 **Botón de Cartita de amor secreta** para que lea una carta especial con fecha y firma.
- 🐰 **Conejita interactiva**: Al hacerle clic, dice frases tiernas de amor.
- 📱 ¡También puedes enviarle la carpeta o subirla a GitHub Pages / Vercel para que lo abra desde su celular!
